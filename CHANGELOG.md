# Changelog

Changes to the Auditable A2A TypeScript SDK. A package version 0.X.Y implements the extension
`auditable-a2a/0.X`; Y counts the package's own fixes and dependency updates.

## 0.1.0 - 2026-10-16

Initial release, implementing `auditable-a2a/0.1` over `auditable-mcp/0.4` through `auditable-mcp-sdk` 0.4,
with an optional binding to the official A2A JavaScript SDK (`@a2a-js/sdk` 1.3, `auditable-a2a-sdk/a2a`). The
Python SDK's 0.1.0 implements the same release. See the README for what it covers.
